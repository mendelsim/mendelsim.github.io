# MendelSim — Simulador interactivo de genética mendeliana

**MendelSim** es una herramienta web estática para aprender y practicar genética en educación secundaria y universitaria. No requiere instalación ni servidor: funciona directamente en el navegador.

## Módulos

| Módulo | Descripción |
|--------|-------------|
| 🔬 Cruce Monohíbrido | Cuadro de Punnett 2×2, dominancia completa / incompleta / codominancia |
| 🧪 Cruce Dihíbrido | Cuadro de Punnett 4×4, proporciones 9:3:3:1, testcross |
| 🧬 Herencia Ligada al Sexo | Genes en el cromosoma X, portadoras, herencia recesiva y dominante |
| 🌳 Pedigríes Interactivos | Análisis de árboles genealógicos, constructor visual, modo práctica para alumnos |

## Características

- Modo oscuro automático (sigue la preferencia del sistema) con toggle manual
- Ejercicios predefinidos y casos aleatorios en todos los módulos
- Constructor de pedigrís con nomenclatura estándar (I-1, I-2, II-1…)
- Modo práctica para alumnos: descarga de respuestas en JSON y envío por correo
- 100% estático: HTML + CSS + JS sin dependencias externas ni frameworks
- Responsive, accesible y compatible con los principales navegadores

## Uso

Abre `index.html` en cualquier navegador moderno, o visita la versión publicada en:  
**[https://mendelsim.github.io](https://mendelsim.github.io)**
